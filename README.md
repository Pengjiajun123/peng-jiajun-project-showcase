# 彭嘉峻 · 项目演示与文档

独立的静态展示网站，仅收录四个项目：

1. AI × GAME：12 页 PPTX 演示稿及 14:44 演示录屏。
2. Z Career Lab：39 页 v4 说明书及 14:34 讲解录屏。
3. 校园情报局：19 页产品说明文档与页面预览。
4. 《家》：1:49 手机端交互录屏及作品概览。

## 本地浏览

在此目录运行 `python3 -m http.server 8081`，访问 `http://127.0.0.1:8081`。页面也支持直接打开 `index.html`。

## 长期部署

网页、文档页面和三段 MP4 视频完整存放在同一个 GitHub 仓库，由 GitHub Pages 提供固定的公开网址。视频经过 H.264/AAC 兼容和网页体积优化，单个文件小于 25 MB。`media-config.js` 记录独立设计作品集的网址。

## 内容维护

`index.html` 为项目介绍与页面结构，`style.css` 为响应式样式，`script.js` 为文档阅读器与媒体行为，`media-config.js` 为固定部署链接配置。

文档网页页数为 12 + 39 + 19 = 70 页，原始 PPTX/PDF 完整保留。所有截图、文档与录屏来自用户指定的作品，未加入其他项目。网页无账户功能、API 密钥或访客追踪。
